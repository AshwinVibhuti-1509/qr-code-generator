\# QR Code Generator



A simple Python web app that generates custom QR codes for any URL.



\## Features



\- Enter any URL

\- Choose a custom file name

\- Select QR code colour

\- Select background colour

\- Choose QR size

\- Preview the QR code

\- Download the QR code as a PNG file



\## Tech Stack



\- Python

\- Streamlit

\- qrcode

\- Pillow



\## How to Run Locally



1\. Install the required libraries:



```bash

pip install -r requirements.txt

```



2\. Run the Streamlit app:



```bash

streamlit run app.py

```
